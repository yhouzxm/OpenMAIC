# 统一试用操作指南

2026-10-26，当前LOCAL合并候选。版本与证据认[P7交接](zhiban-v2-p7-handoff.md)及其manifest，历史指南不覆盖本页。

## 启动和账户

```sh
pnpm trial:zhiban:info
pnpm trial:zhiban
node scripts/zhiban-handoff.cjs status
```

已运行时只执行info，不重复启动。入口 [3461 工作台](https://127.0.0.1:3461/zhiban)。默认恢复原三库、用户ID、课程与历史；首次无快照才初始化。管理员王管理员、教师周老师、学生陈同学均为合成账号。完整登录标识及密码只在info指向的owner-only账户文件；切换角色先退出，同一主机不同端口共享Cookie。

环境为Ubuntu PG16、Node22、pnpm10.28.0和本机受信开发证书。私有PG仅Unix socket，不使用真实55432／55433。模型与扫描器配置由主机独立保管；解析服务未配置时界面诚实提示，不用模拟成功替代。

## 保存与恢复

```sh
pnpm trial:zhiban:backup
pnpm trial:zhiban:backup:verify
pnpm trial:zhiban:stop
```

停止保存成功后清理临时root，下次启动保持账号与历史；失败保留现场和上代。快照含敏感数据，只存本机私有目录，不进入源码包。异常恢复及明确升级入口见[恢复说明](zhiban-v2-persistent-local.md)，不要手动删锁／数据绕过检查。

默认启动不执行全量回归。显式disposable和专项验证只在需要时运行，不与当前3461争用端口；不因一次页面核验重复CI。旧Native维护、真实解析服务、当前包跨机／PG18／生产与真实账户运营仍未签收；历史远端旧包PASS保留原适用范围。普通阅读／聊天、学生自报实验均不直接计正式成绩。原生刷新／关闭复验按用户要求延期。


## 近期能力的一次使用入口

教师课程资源 → 原生备课工作台 → 编辑／资料／Agent → 核对完整课件 → 采用草稿 → 审核发布；固定课件内进入原生 AI 课堂并按版本启用，自主 PBL 单独启用。教师／学生的私人课堂状态分别保存。

教师课程内「课堂成果与共享结果」配置已发布文字活动与固定 Quiz／PBL／反思场景；学生在该页开始尝试，进入原生场景后核验并确认正式提交；教师仍用原待评分入口发布，学生回看原成绩与教师已发布的完成规则。默认原课程保留真实 PBL、人工 92/100 与原 90% 规则达标示例；不必重做该旅程。教师可显式发布／撤回课堂小结和本人板书文字，Tutor 仅受限读取／检索当前固定资料。

教师工作台／固定课件 →「课件归档与恢复」导出六种稳定格式，MAIC／PPTX 经当前扫描器恢复为本人新副本，再审核采用发布。管理员教务 →「服务与运行中心」查看配置／状态、用量与审计；主机锁定项只读。未配置的多模态／语音服务不显示为已验收。

近期完整清单、安装／恢复制品与证据范围统一见[P7交接](zhiban-v2-p7-handoff.md)，不逐入口重新打包。
