# 界面环境提示与正式文案

2026-10-28，LOCAL。本轮仅调整界面呈现，不修改身份授权、账户开通协议、扫描放行条件、评分规则、已应用迁移或既有证据来源。

## 环境配置

使用 `ZHIBAN_UI_ENVIRONMENT`，只接受小写 `local`、`test`、`production`。拼写错误或空值拒绝启动。默认持久化入口读取本机私有 `.env.local` 中的此项；显式进程环境变量优先。PG16／PG18 当前本地 host 未配置时使用 `local`，不以 `NODE_ENV=production`、端口、域名或网址参数推断界面环境。

| 配置 | 所有系统页面 | 登录提示 |
| --- | --- | --- |
| `local` | 本地体验环境 · 仅供体验与验证 | 请使用本地体验账号登录。 |
| `test` | 测试环境 · 仅供体验与验证 | 请使用分配的测试账号登录。 |
| `production` | 不显示体验／测试提示条 | 不显示体验／测试账号提示 |

环境由服务器在 HTML 中输出，前端不接受网址参数或浏览器存储切换。原始静态模板采用正式文案；没有环境属性时也不显示本地提示。页面功能标题保持显示，不把现有 `.local` 样式类误判为环境标记而整体隐藏。

本机核对正式外观时，先正常停止并保存，再显式启动：

```sh
pnpm trial:zhiban:stop
ZHIBAN_UI_ENVIRONMENT=production pnpm exec tsx scripts/zhiban-local/start-persistent.ts --upgrade-local
```

后续源码一致时可用 `ZHIBAN_UI_ENVIRONMENT=production pnpm trial:zhiban`。改回 `local` 也须正常停止后重新启动。不要并行启动多个实例占用同一端口。

**`production` 只选择正式界面文案。** 本地合成数据、LOCAL receipts、隔离运行、证书与维护门禁均保持原有属性；它不构成真实云部署、真实用户运营或生产启用签收。旧维护交付链未接入本轮环境条，不修改其冻结安装包。

## 文案统一范围

- 检查全部系统 HTML 页面，以及登录、工作台、教务、账户、课程内容、评分、画像与支持的源文案；排除生成 bundle 和用户课程数据。
- 登录页去除固定的“本地开发环境”与 `LOCAL` 页脚，改为统一环境条；密码眼睛功能保留。
- 统一“首次登录，设置密码”入口与页面，使用“密码设置凭证”；保留本人设置、一次性凭证与原账户开通边界。
- 连接失败提示改为重试／联系管理员；不要求普通用户检查本地服务。
- 将面向师生的 `REVIEW`、`Enrollment`、旧链接 `Native/Runtime` 实现术语改为审阅状态、选课记录和可操作说明。
- 侧栏旧“待移植”提示改为“从课程内进入”或“暂未开放”，不改变入口授权与可用范围。
- 区分“上传素材／当前输入”和运行环境，解析转换明确在服务器执行。
- 未启用内容页使用功能状态说明；真实服务不可用、未审阅维度、学生手动记录以及合成样例未通过真实扫描等说明仍保留。
