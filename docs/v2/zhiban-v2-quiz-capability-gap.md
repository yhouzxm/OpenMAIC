## 复用时必须保留的成绩边界

当前智伴已绑定固定发布版本、Attempt、提交答案 hash 与测验 hash；正式提交由服务端计算客观结果，简答标为待人工。解析／答案按现有复核开放规则投影。进度与总评只认原正式来源，不能读 Native localStorage 或直接信任客户端分数。

原生 `/api/quiz-grade` 接收请求中的题目／答案／分值，并不提供智伴课程、Attempt、提交与版本授权。其模型输出解析失败还会回退为半分；因此不能直接复用其响应为正式成绩。后续若引入 AI，复用模型解析／调用基础设施，服务端取正式快照、校验当前教师权限；模型失败明确待处理，建议可拒绝，由教师确认后沿原评分管线发布。此为建议边界，未实现或进行真实模型验证。
