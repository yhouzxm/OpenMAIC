## 已确认并实现的规则

每题2–10个项目，教师配置唯一正确顺序及整题正分值（最多两位小数），不支持并列。学生用上移／下移排序并明确确认作答；确认后顺序完全正确得整题分，否则零分，不按正确位置、相邻关系或编辑距离给部分分。单卷仍受100题／1000分及原容量边界限制。

教师可以增删／编辑项目、调整标准顺序、设置分值和解析，删除整题。新增或删除项目清空标准顺序，须重新配置后发布；缺标准顺序可存草稿，发布必须是全部项目ID的不重复完整排列。发布时项目文字不能为空或去首尾空白后重名。改文字保持项目ID与配对身份；题目／整卷复制保留独立嵌套内容并生成新题ID，项目ID只在该题及固定版本内使用。

学生初始未作答；上移／下移只形成未确认草稿，不自动得分。点击“确认当前排序”后才计为已答，之后再移动会撤销确认。未确认候选可保存并刷新续作，提交确认仍将它计入未答；直接提交未确认候选得零分，即使候选恰好正确。清除作答回到未确认初始状态。保存／开始Attempt不会自动确认。

正式成绩沿原教师确认、发布与更正；覆盖客观得分仍须该题公开原因及公开更正理由。教师人工更正是显式例外，不改变排序自动判分的全对／零分规则，不回写旧答案键或自动结果。

## 数据、公开投影和版本

Quiz JSON 增加 `type: ordering` 与 `ordering.items[{id,label}]`、`ordering.correctOrder[string]`。排序答案为 `{order:string[], confirmed:boolean}`，与原生、填空和匹配题答案形状分开校验。缺席答案规范化为空顺序／未确认；非空顺序必须是全部项目ID的完整排列，确认状态必须为布尔值。拒绝缺项、重复、外来ID、用显示文字冒充ID、旧数组形状及额外分数／权限字段。

确认标志仅表达学生自己的作答状态，不是教师许可或独立授权凭据；操作者、Attempt归属、提交规则、成绩权限仍来自原可信宿主。

公开投影只含题干、分值与项目ID／文字。项目按固定ID排序作为中性呈现顺序，独立于标准顺序和作者项目数组的顺序；改变答案键不会改变公开顺序。不返回 correctOrder、解析或评分指引。教师及学生复核开放条件沿原规则；封卷后学生回看的是本人Attempt固定版本的标准顺序。

含排序题的整卷使用独立本地组合算法 `zhiban-quiz-order-1`；没有排序的卷继续保留原生／填空／匹配算法标识，混合卷复用它们原有的计分逻辑。版本、quiz hash、answers hash、算法和判分结果沿原不可变快照／提交保存。旧Attempt不因新版标准顺序、项目数组顺序或当前草稿变化而回算；已提交未确认结果也不会被后续确认重交覆盖。

source_pin 保留原生基础能力pin，不作为上游排序实现证明。本地算法、宿主和验收源码由本包独立hash绑定。
