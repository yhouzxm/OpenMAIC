## 课程授权与固定资产

- 只接受智伴真实 Session，逐请求核验当前课程任教；owner 由租户、教学班、Membership 摘要派生，客户端不能指定。学生、管理员及其他课程不能直接使用教师备课 API。
- 显式原生路由白名单，不开放通用代理、匿名 owner、上游公开发布或旧浏览器全局导入。私有文档与资产拒绝原生 capability-by-id 跨课程读取；会话、技能和资料继续使用原生 owner 隔离。
- 模型与工具边界、排队任务及 SSE 交付再次检查当前任教。已开始的供应商请求可能完成私有中间工作，但撤权后不能继续工具／交付／采用／发布。普通发布沿原 Content/Identity/Bridge 并发屏障。
- 完整 AppDocument 与全部引用资产形成 SHA256 来源摘要。采用在独立私有 Native 库事务中固定文档、资产 MIME、字节和摘要；追加表有来源 receipt、关闭 ACL 和不可变触发器。没有修改已应用 migrations。
- 正式 Content 保存快照标记，仍由原有发布与当前课程授权决定可见性。文档、媒体、HTML frame 每次读取核验当前发布；撤回或名册／任教变化不靠浏览器缓存放行。AV 支持有界 Range。HTML 为独立 opaque sandbox，无远程依赖。
- 文档限 128 场景／8MiB，最多 256 资产、每资产 32MiB、合计 128MiB；缺字节或未支持的引用拒绝采用。HTML 遵循既有受限离线策略，不扩大为任意远程脚本。
