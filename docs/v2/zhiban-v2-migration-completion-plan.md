## 4. “完成”分四个可检查的口径

1. **已有业务的界面完成**：P1对应需求有可用布局、导航、交互、返回上下文和响应式；新版OpenMAIC满足或更好时采用其界面，不强制还原旧像素。仍缺业务的高级页面不能随之标完成。
2. **课程教学版本可用**：至少 P1＋P2，三角色能完成建课／开班／编排／发布／学习／提交／评分／读反馈；这是有限范围可用版本，不是全量迁移。
3. **已批准需求的本地交付完成**：55路由／36能力均有明确去向：复用新版、薄适配、补差额、确需移植或被新版取代；REVIEW有明确决定。所有实际保留需求在同一版本可用，不要求保留被新版取代的旧页。占位页、禁用菜单、隐藏入口和单元测试不单独满足此标准。
4. **生产可上线／真实数据迁移完成**：生产凭据、部署、备份恢复、容量、日志、真实账户与数据核对、回退和明确 release 签收另计。以上本地完工不替代生产门禁，也不要求每轮重复 GitHub CI。
