# P3 个人资料、账户与成员目录合同

2026-10-18，沿原P3，LOCAL候选。旧分支固定 `0fa0a15e8b12ae9e4f7a2d78e80338874599bbae`，新版固定官方1.2.0 `a9da60b3b4adb429369c0da13d5637a904ead2b0`。

旧版 student/teacher/profile 具有显示名、联系方式和简介；admin/accounts 与 directory/users 具有跨角色名录及正式档案。新版 settings 主要为模型／课堂配置，没有智伴租户成员档案公共合同。复用当前工作台、学生目录、身份验证和原本人密码API；只补资料与全成员目录差额。学号／工号是业务来源标识，不能照搬旧版作为全局登录凭据。

## 本轮交付

- 各角色在当前空间进入“个人资料与账户”，编辑显示名、邮箱、QQ、微信、简介；显示名用于本空间课程和讨论，不是核验后的正式姓名。联系方式与简介只向本人返回，管理员目录不读取这些字段。显示名最多120字，邮箱254字、QQ32字、微信100字、简介2000字，纯文本呈现。
- 本人可查看 UserId 登录标识、当前成员状态和当前角色。账户安全复用冻结本人改密／退出全部会话入口；密码不进入资料库、命令收据、日志或本地存储。改密后重新登录，超时不自动重放密码请求。
- 管理员在现有学生目录之外增加“成员账户目录”，按角色、成员状态及名称／完整成员ID／学号／工号搜索，分页查看全部本租户成员，维护正式姓名、学号和工号；查看账户UserId、成员状态和当前角色。正式姓名和编号对本人只读，成员可同时有多个角色，不强制旧版单一 accountType。
- 学号、工号各自在本租户内不区分ASCII大小写唯一，允许空值；仅管理员维护，不自动授予学生／教师角色。编号为1–64位ASCII字母、数字、点、下划线和短横线。UI明确业务编号不是登录账号。

头像及上传、外部目录／组织树、多类导入、全球唯一登录别名、直接开户、管理员改他人密码、直接启停User／Membership和角色变更不冒充完成。现有默认host的 membership/operator 输入仍为空；这些操作继续受既有入驻、同意、审批与冻结授权合同约束，不通过业务表旁路实现。资料和目录的交付不改变这一边界。

## 数据与并发

新增独立 `zhiban_profile` schema：本人私有 profile、管理员 directory_record、追加命令／审计。所有行有 tenant＋membership FK，强制RLS；仅给业务runtime必要字段更新权限，无DELETE、DDL或SECURITY DEFINER函数。独立 successor migration显式给既有 `zhiban_academic.people.display_name` 单列UPDATE，原迁移字节不变；保存本人资料和同步显示名在同一事务完成。不得给业务runtime Identity写权限。

每次操作经 AcademicStore.run 取得真实会话／Tenant／Membership和权限锁，管理员写入必须持有效租户管理员授权，并核对目标同租户成员。私有资料只按 actor Membership读取，API不接受别人的owner或角色。读写均不因客户端缓存而跳过撤权检查。

新记录的 expected revision 为 null，既有记录为字符串revision；actor／目标／payload／命令号绑定，未知结果原号重试，冲突保留输入并显式读新状态。本人profile锁和目录record锁互不覆盖对方字段；审计只记录动作、对象、修订和字段名，不复制联系方式／简介／密码。编号冲突的唯一约束失败回滚资料与审计，不泄露占用者。profile行、people显示名及命令同事务，无半更新。

新授权列改变 Academic catalog，须独立构建 Profile组合 expected PNG参考，保留旧Quiz参考原scope；仅默认统一试用选择新参考。另建 Profile schema／ACL只读loader，来源／catalog／owner／RLS／角色／唯一迁移ledger不符即关闭。只在owned PG16安装；真实55432／55433不操作。

## 查询与页面

`/api/zhiban/profile/:tenant/me` GET/POST只服务本人；`/members` GET为租户管理员分页目录，POST为管理员正式档案命令。限制query字段、JSON大小、CSRF／Origin及并发数；使用现有安全传输边界。目录使用MembershipId keyset和服务端HMAC cursor，绑定租户、actor、过滤器和页大小。跨数据库筛选每次最多扫描200个候选，若无匹配但仍有候选，返回明确下一页，不能声称全库无结果。

页面沿用工作台／管理员壳，保留当前空间及返回入口。未保存离开可取消，失败／冲突保留输入，未知结果锁住编辑并原命令重试；登出跨标签清空已挂载资料。目录只呈现允许的成员与正式字段，不返回私有联系方式。
