# 智伴 V2 当前操作指南

2026-10-23；本页替代[旧指南](zhiban-v2-trial-guide-history.md)中的当前状态，旧证据按原日期保留。仅合成 LOCAL 教学，不是生产迁移或全量高级能力签收。

## 启动与账号

项目根 `/home/zxm/openmaic/zhiban`，Ubuntu PG16、Node22、pnpm10.28.0、已受信开发 CA。先运行 `pnpm trial:zhiban:info`，使用其当前 URL 与 owner-only 账号文件。完整 UserId 是登录账号，显示名、MembershipId、学号／工号不是账号；确认过的 `@标识`是独立入口。

已有实例则直接接续。需要新数据且没有实例时运行 `pnpm trial:zhiban`，保持终端运行；停止用 `pnpm trial:zhiban:stop`。停止会删除本次三库，不是持久部署；新 tenant／offering／密码替代旧书签。不同端口共享 Cookie，换角色先退出。

若浏览器报证书错误，核对本机 `/home/zxm/.local/share/zhiban-m1/receipt.json` 与受信开发 CA，不绕过警告；路径和环境交付边界见[交接环境说明](zhiban-v2-p7-handoff.md)。证书私钥、CA 私钥和密码均不随源码包分发。

## 其他已交付入口

- 管理员“教务批量导入”：七类 CSV，最多50行／64KiB；预览、逐行原子、失败即停、本人持久批次和结果下载。环境重建后原批次不保留。旧 classes／students／registrations 入口映射到对应类别；users 进入独立受控开户申请。
- 教师“教学分析”：事实名单、人工记录／结案、显式站内提醒与确认、补救任务／效果、默认关闭的规则审阅、概念证据、引用式学习观察。维度仍 REVIEW，不计算认证掌握。
- 课程讨论：主题／回复、教师关闭／重开及隐藏／恢复；使用当前课程授权。
- 教师 AI 备课：复用原生生成→采用→草稿→显式发布，需实际模型配置。Tutor 默认关闭，由任教教师显式启用；本人私有历史，不改成绩。
- 个人资料／账户：本人资料、安全入口及登录标识；管理员只能维护本空间正式档案和受控成员关系。global 开户／启停／标识提名依赖独立平台来源，网页不获得全局写权限。

## 受限能力与故障处理

扫描器当前不可用时，新扫描附件与资源上传拒绝；不要重签旧 pin、启用合成扫描或重跑无关扫描测试来“绿灯”。文本／PNG 与普通教学可继续。Office／OCR／音视频需要解析服务，缺失只阻塞对应能力。

提交结果未知时读取原批次／命令／尝试，不生成新键或新尝试自动重放。原生刷新／关闭未保存保护按此前用户指示延期，编辑后先显式保存；应用内离开保护的旧证据保留原范围。

模型配置缺失不代表生成成功；旧真实 GLM 旅程不是本轮重新调用。当前普通启动与已有私有模型 launcher 的区别、源码包恢复前提和所有 deferred gates 见[交接包](zhiban-v2-p7-handoff.md)。

## 成绩簿跨页下载（2026-10-23）

教师课程 → 成绩簿 → 先查询学生 → **按查询条件跨页导出 CSV**。忽略当前学生／活动页，导出当前在班匹配学生与当前发布活动的公开成绩，最多500人、100项、10,000条、8 MiB；超限拒绝，不截断。未点击查询的新输入不生效，原当前页导出保留。详见[产品与LOCAL证据](zhiban-v2-gradebook-export-local.md)。默认3461已刷新为新合成数据和新账号；此前P7包保留原范围；当前统一包已纳入后续入口增量，身份以最新[P7交接](zhiban-v2-p7-handoff.md)的manifest为准。历史课堂记录不作当前实例数据。

## 本人头像（2026-10-23）

个人资料与账户 → 选择PNG头像 → 上传并保存；支持替换和移除，最大96×96／12 KiB。头像仅本空间本人及管理员受限成员目录可见，文字资料独立保存。更多格式先自行转换为小尺寸PNG；[本包说明与证据](zhiban-v2-avatar-local.md)。

## 管理员与登录旧入口（2026-10-23）

`/zhiban/login`复用当前UserId／已确认@标识；`/zhiban/admin`核对当前空间管理员资格后进入工作台；`/zhiban/admin/users`进入原受限成员账户目录。匿名链接提供固定同源登录后返回并保留空间，教师／学生不会因此获得管理员权限。旧删除／重置密码与手机号／学号登录不恢复，详见[LOCAL包](zhiban-v2-admin-login-routes-local.md)。

## 画像与学习支持入口（2026-10-23）

教师侧栏“学习分析／风险预警”、学生侧栏“学习档案／学习支持”可选择当前有权限的教学班，进入课程聚合页及原功能；原功能页有固定返回。学生只读本人已公开内容，不展示教师风险审阅。维度继续REVIEW，空记录不生成能力结论。详见[LOCAL包](zhiban-v2-support-routes-local.md)。

## 教师 AI 备课旧入口（2026-10-23）

教师侧栏“AI 备课”选择任教教学班，或从课程内“AI 备课”进入。旧 `/zhiban/teacher/agents` 与课程内agents现复用已有文字备课，面板自动展开；生成→确认大纲→审核采用→编辑保存→显式发布仍分别操作。旧干预Agent／监控／Peer未启用。课程列表及采用草稿返回保留上下文，详见[LOCAL包](zhiban-v2-authoring-routes-local.md)。本轮入口验证不重复调用模型，原真实模型证据保留原范围。

## 学生 AI 工具旧入口（2026-10-23）

学生侧栏“AI 学习辅导”选择教学班，或从课程内同名导航进入旧tools路径，复用原课程Tutor。教师尚未启用时不能新建／提问；本人已有历史仍可查看。旧tutor路径与tools共用数据，教师不能读取学生私人会话；Peer未启用。本轮合成空会话已结束，未发送模型问题，教师开关恢复关闭。详见[LOCAL包](zhiban-v2-student-tools-routes-local.md)。

## 教师课程设置与任教名单（2026-10-23）

进入教师课程后，使用“课程设置”查看本教学班引用课程版本、学期、容量及状态，并前往原目录／讲义／AI／Tutor设置；基础配置修改请由管理员处理。“任教名单”只读当前教学班关系和姓名，可搜索分页，不展示联系方式、账号或角色。关系不代表实时有效授权；无上下文旧书签先返回工作台选空间和教学班。详见[LOCAL包及检查限制](zhiban-v2-course-administration-local.md)。
