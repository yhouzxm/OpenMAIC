## 下一片：基础课堂共享任务闭环

确定先交付“教师选教学班 → 组织一次课堂 → 发布已有讲义或文字活动 → 学生看到并进入 → 原流程作答 → 教师查看真实提交并结束任务”。这是 V2 对旧入口的有限适配，产品标注“基础课堂”，完整 OpenMAIC Classroom 仍为待办。

范围包括：

1. 教师课程内“课堂与互动”保留现有活动管理，新增课堂列表／详情、标题和说明、草稿／发布、可选开放／关闭时间；全局课堂入口复用授权列表，不另建一套数据。
2. 新课堂实例绑定 tenant／Course／Offering；实例、派发记录和学生参与记录使用独立标识，不能复用身份 SessionId、Content ID 或 Attempt ID。
3. 教师从本教学班已发布目录可访问的文本／PNG 讲义、已发布 TEXT_RESPONSE 活动中选择任务。派发记录固定目标版本；不隐式发布内容／目录，不接受任意 URL 或原生 Stage ID。版本不可读时拒绝或提示重新选择，不能静默换成最新版。
4. 学生在课程工作区看到当前开放课堂与任务，支持手动刷新及有界同步，进入现有阅读／作答页；返回保留课程、教学班和课堂上下文。已有未保存作答保护继续生效。
5. 结束当前任务或课堂后，拒绝新的课堂加入／任务进入；已有讲义和作答能否访问仍由原内容／活动规则决定。结束课堂不自动提交、完成、评分、取消已有 Attempt，也不改变截止时间、重交与尝试上限。
6. 教师查看参与和提交事实，区分“已进入”“已提交”“已发布成绩”；阅读不显示伪造完成率，参与不等于签到认定。成绩继续走原人工评分流程。

实施前在同一片补齐会话／派发状态转换、版本与并发、授权和审计的精确增量设计。采用新应用服务／端口与追加候选存储，复用现有 Identity、Enrollment、内容和作答授权；不修改已应用 migrations，不借普通 UI 接线开启 Runtime。下一片的可用签收必须覆盖上述实际旅程，单独增加卡片、空页面或 disabled 按钮不算完成。

### 授权与并发底线

- 每次列表／详情／发布／进入／同步请求都检查当前租户、角色、membership、教学班关系；教师必须当前任教，学生必须当前有效 Enrollment。管理员不因管理角色自动获得教师派发权限。
- URL 中的 Course／Offering／课堂／任务必须由服务器校验同一归属。草稿、未开放、过期、隐藏及错误教学班的直接 URL 均拒绝。
- 教师结束／改派与学生进入的竞争使用版本校验及事务屏障；发布／进入按幂等键去重。同键不同内容拒绝，不能靠前端按钮防重。
- 撤权后下一次请求拒绝；定时刷新不构成授权缓存。具体同步周期与最大显示滞后须在实现设计中给出，界面滞后不能延长后端权限。历史提交／成绩按既有历史访问策略保留，不因退班删除。
- 客户端“进入／阅读”只能作为观察；浏览器自报完成、成绩、时间及点击不能变为可信学习结果。审计记录派发者、目标及版本、状态变化和服务器时间，避免收集无必要的答题正文。

## 完整迁移仍须完成的后续范围

- **U01 完整课堂**：正式版本化 host／bridge、受限 launch 与 Attempt 绑定、多场景和已声明 Action、保存／恢复／重连／取消、资源授权、真实播放及 Quiz。按执行计划 7A 核验公开合同；缺少时提出独立有限引擎 ADR，不复制 Zustand／私有 playback。取得可运行合同时才能确定实现工期。
- **U02 Interactive／VirtualLab**：独立 origin、sandbox、局部 CSP、消息绑定、撤权停止、服务端 action／measurement／evaluation；按类型开放 HTML／3D／虚拟实验。机电 line-stop、25-scene／station 注册表不进入通用核心。
- **高级编排与分析**：Scene 先修／补救／挑战、可信 LearningEvent、完成规则、进度与导出；AI Tutor／Peer、EMA、PBL 分批设计交付。REVIEW 项仍保留待决定状态，不因本清单自动批准全部规则。

以上继续遵守冻结设计及各自 Gate；普通共享任务不等待真实维护 broker／Native 输入，但也不扩大已有 Bridge receipt 的适用范围。UNKNOWN／RESERVED 和真实环境启用保持原隔离状态。
