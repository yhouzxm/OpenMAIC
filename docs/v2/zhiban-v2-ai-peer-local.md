# 课程 AI 学习伙伴

2026-10-24，沿原P6接入新版原生Agent与现有课程Tutor。首包为私人学习讨论伙伴：教师单独开启，学生选择“AI辅导／AI学习伙伴”后建立固定类型的会话，提问、取消、关闭、历史回看共用已实现的课程授权和限额。界面始终标明AI，不冒充同学、不访问其他人的对话，不提供心理诊断、自动预警或正式评分。

新增Tutor/0002只加默认false的peer_enabled和默认TUTOR的不可变会话style。旧会话仍是Tutor；旧请求摘要保持不变。学生不能开启教师策略；教师策略使用revision CAS；新建幂等去重。当前策略、Enrollment、任教和本人会话授权在生成前后核对，撤权／关闭／取消使在途回答不交付。SQL runtime没有修改会话style的权限。原schema迁移未改，独立fresh PG16预期profile重建，loader验证全部迁移checksum、catalog和ACL。

本地证据 `evidence/zhiban-peer-local.json`、`evidence/zhiban-peer-local.png`：真实模型回答保存并在学生浏览器显示；默认／关闭拒绝、学生提权拒绝、并发策略一胜一冲突、重复新建、教师／管理员不得读取学生私人会话、生成途中关闭不交付、本人历史保留和style列权限验证。首次浏览器脚本使用旧按钮名、随后错误等待登录按钮改名，已改为等待登录响应和表单移除；复验复用已保存真实回答，没有以替身补成功。额外一轮真实生成用于在途撤权检查。

演示班已由本地教师账号启用学习伙伴；其他教学班默认关闭。真实模型来自已有本机受限GLM配置，receipt保留模型标识和回答hash，不保存密钥。

范围边界：这是学习伙伴首包，不是PBL多人协作、临床心理服务、跨人私聊分析或危机处置平台。其余P6及P5扩展沿集中执行单继续。
