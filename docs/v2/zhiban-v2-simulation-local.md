# 固定模型的服务端模拟实验与原成绩闭环

2026-10-24，原P4完整课堂／实验包接续。首包明确为 **SERVER_CALCULATED_SIMULATION（服务端计算模拟）**，不代表仪器测量、真实设备、Native Runtime自动采集或自动正式评分。复用Flow固定教案、原Learning Attempt、实验报告与Assessment发布／更正及学生历史；最终验收以 `evidence/simulation/closeout.json` 为准。

## 模型与可用流程

| 固定版本 | 计算与单位 | 限制 |
| --- | --- | --- |
| DC_OHM_V1 直流欧姆定律 | 电压U单位V、电阻R单位Ω；I=U/R，P=U²/R | U为0–240，R为1–1,000,000；理想线性电阻，不含温升／容差／仪表误差 |
| RC_CHARGE_V1 RC充电 | 电压V、电阻Ω、电容μF、时间s；τ=R×C×10⁻⁶；Vc=U×(1−exp(−t/τ))，I=U/R×exp(−t/τ) | 电容初始电压为零；C为1–1,000,000μF，t为0–3600s；理想串联RC，不含寄生参数 |

教师在“教案与实验”的LAB环节选择手填／服务端模拟模型。模拟字段、单位、范围和计算式由版本固定，教师编辑说明和结论要求，保存后显式发布；不能提交任意公式、脚本、命令或网络地址。手填LAB保持原结构与LEARNER_REPORTED来源，旧报告不重写。

学生按课堂进入，选择参数，点击“运行模拟并保存结果”。服务器即时计算并保存；表格数值／运行来源只读，本人填写结论。允许同一实验记录最多50次运行，全部保留。更改参数必须再次执行，不能将未执行参数或客户端填入的结果作为报告。刷新恢复数据库已保存的输入、结果和结论。

正式提交固定本次报告及其运行集合；教师可查看每次输入、模型与执行器摘要，再沿原评分发布／更正，学生查看对应提交的已发布成绩。运行本身不产生完成、学分、证书或成绩；后续重交是否允许仍按原活动规则。后续运行不能改变先前报告引用或已发布成绩。

## 来源、授权与并发

每次运行追加不可改写证据：所属notebook／Attempt／学生由原关系链确定，保存模型ID／版本定义hash、实际执行器源码hash、输入与输出hash及服务端时间。算法输出保留12位有效十进制数；这是模型计算精度，不承诺物理测量精度。宿主读取经本地receipt验证的源码，模型实际计算与来源均由受限服务端执行；不接受iframe消息／客户端分数升级成可信证据。

RUN_SIMULATION复用真实学生授权、当前Enrollment、最新Attempt／活动版本、截止及重交规则。课堂／教案必须运行且当前派发与记录一致；暂停、结束、切换环节后拒绝新增模拟。先锁定课堂，再串行锁notebook，配合原Identity／教务屏障及revision／Attempt revision CAS；同key重放返回同一结果，不重复计算入库。计算、原Learning修订、记录、审计与命令结果在同一事务，后段故障完整回滚。

课堂结束后已取得结果可依原活动规则保存结论及提交，不强行锁死已有作答。历史读取仍按当前任教／本人资格，不接受别班、跨学生或跨租户拼接。原Native维护控制根、签名、公钥pin、55433及UNKNOWN／RESERVED隔离均未使用或解除。
