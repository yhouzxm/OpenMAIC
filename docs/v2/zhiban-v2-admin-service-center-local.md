# 管理员服务与运行中心（LOCAL）

沿原 P3／P7 复用当前 OpenMAIC 模型配置、媒体适配器及统计能力；在原教务后台增加「服务与运行中心」。入口 `/zhiban/admin/services?tenant=<当前空间>`，默认本地 HTTPS 3461。此包不替代平台维护链，不要求重复课堂回归。

## 可用范围

- 服务状态：语言模型、图像、视频、TTS、ASR、文档解析的关闭／未配置／配置待查状态；状态读取不自动调用服务商。
- 服务配置：直接使用原生 `ModelServicesPanel`、`ServerSettingsGate` 及服务面板。原生提供者、模型列表和端点校验继续生效；密钥仅写入服务端，界面只见掩码。原生不允许网页配置的密钥对、私有端点及部署项仍由主机管理。
- 教学模型分配：复用原生 `CourseModelMap`。当前空间默认值接入原生教师备课、生成任务、课堂／自主 PBL、多模态宿主和课程 Tutor 的模型解析；已有个人槽位选择保留，空间提供者同名时优先于个人定义，部署提供者／锁定与 `allowUserKeys` 仍有最终优先权。
- 连接检查：只接受已保存的提供者 ID、可选模型和当前空间配置版本，复用原生语言模型、图像、视频、文档检查及模型发现。状态页另提供 TTS 固定短句合成和 ASR 一秒静音样本检查；结果不回传生成音频或原始提供者响应。语言模型／TTS／ASR 检查可能产生少量用量。成功只证明该次调用，不证明教学质量、完整素材解析或正式学习完成。原生面板内的录音／试听预览仍使用教师多模态入口，不转为管理员任意文件上传接口。
- AI 用量：复用原生聚合与 `UsageDashboard`，按月份显示本空间可信标记的次数、token、图片／秒数／字符量。未归属的历史日志及其他空间记录排除；不推算费用，不写正式成绩或 Runtime 完成。
- 变更记录：分页记录操作者成员标识、配置版本、涉及槽位／提供者、密钥是否变更及连接检查结果，不记录密钥、端点、提示词或原始错误。无自动探测、自动恢复密钥或静默重试。

## 授权、并发和数据

所有读写都通过现有 AcademicStore／Bridge 的当前会话、成员、TENANT_ADMIN 和授权版本屏障。同空间不同管理员可共同管理；教师、学生及其他空间管理员不可访问。修改与检查还须原 Origin／CSRF；不可通过浏览器提供 owner、tenant、临时 API key 或探测 URL。没有把 TENANT_ADMIN 提升为平台管理员：部署文件及主机全部用量保持隔离。

空间配置存入原生私有 `workspace_model_config`，owner 为服务端派生的 `zhiban-services:<tenant>`。复用原生 AES-GCM 密钥加密及修订 CAS；命令重试比较实例密钥 HMAC 指纹（再加密），不在审计中重复保留旧明文密钥。配置和审计在同一原生事务提交，审计失败则配置回滚。失去 ACK 的重试返回当前视图，绝不覆盖其他管理员的较新变更。

新增独立宿主迁移 `service-center` v1，仅包含 `zhiban_service_events`、不可跨空间重新绑定的 `zhiban_service_owners`。不修改已应用迁移或 Identity／Bridge ACL。拥有者到空间的关联在受授权的宿主请求建立，后台任务／重启后使用该可信关联解析默认值。

连接检查每空间最多一个、每进程最多两个，并持有 PG advisory lock 防止多进程重复启动；45 秒后结束 HTTP 等待。提供者若仍执行，名额和锁保持到其 promise 结束。已发起检查先持久记录；同命令不会重发。配置版本变化或执行期间撤权，不交付过期结果。`CHECK_STARTED` 没有终态时显示运行中／结果待查证，不假定失败或可重放。供应商未配合 AbortSignal 时仍可能继续计费，不承诺远端撤销。

配置数据库、审计、拥有者关联、媒体、资料、用量和 `native-secret/instance-secret.key` 均位于本地拥有的持久化备份范围。环境 `OPENMAIC_SECRET_KEY` 若由运维提供则仍优先，其交付与恢复须由运维保管。不得把这些私有文件加入 Git。多实例共享数据库还须使用同一实例密钥和受控日志存储；本包不宣称分布式日志合并已验收。

当前默认主机的原配置为 `lock: all`、`allowUserKeys: false`，因此网页配置保持只读；没有改写私有配置或解锁。这不阻止查看状态、检查已保存服务、本空间用量和审计。可编辑正向流程使用独立 disposable 测试配置，明确开启空间委托、使用合成密钥且不访问服务商，不声称默认主机已开放网页写入。

## 验证及边界

本地独立 PG16 检查覆盖真实 Identity／HTTPS、管理员范围、写入密钥不回显且数据库无明文、重放／冲突、并发 CAS、审计失败原子回滚、CSRF、拒绝临时探测目标、教师继承空间服务配置、用量隔离、管理员撤权，以及桌面／390px 页面。

注入测试和合成配置仅用于本地边界，不构成真实外部服务成功。外部 Office／OCR、图像／视频、TTS／ASR 仍未配置，真实成功待相应输入。配置中心可以准备这些受支持提供者；不能用保存成功冒充已启用或验收。

原教务资料解析的独立受限 parser profile 若存在仍按原 pin 管理，不由网页覆盖；本包的空间服务继承首先用于原生资料／多模态链。主机专用解析器、扫描配置、TLS、维护 broker、Native 恢复及可信签发输入继续在原维护边界内。

下一完整功能沿原 P4／P6 推进课程侧可信执行与正式完成桥接，旧维护链保留隔离。建议 GPT-6.1 Sol / high；实际服务配置具备后集中补真实验收。
